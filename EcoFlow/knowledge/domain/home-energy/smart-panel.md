# 家庭能源管理 — Smart Home Panel + 光储协调 + 并网控制

## 业务概述

本文档是 EcoFlow Smart Home Panel 2 家庭能源管理系统的**唯一事实来源（SSoT）**。覆盖电网/离网切换（ATS）、负载优先级管理、光伏-储能-电网三方协调、并网逆变器控制、CT 电流采样、总线通信和系统级故障隔离。

硬件平台参数：

| 参数 | 值 |
|------|-----|
| 主面板型号 | Smart Home Panel 2（SHP2） |
| 负载回路数 | 10 路可控断路器（最大 30 A 每路） |
| ATS 切换时间 | < 30 ms（配合 UPS 模式）|
| CT 传感器类型 | 开口式罗氏线圈，量程 ±200 A |
| 总线协议 | RS485（Modbus RTU）+ CAN 2.0B |
| 电池系统 | DELTA Pro Ultra（LFP 16S，51.2 V 标称，[详见 RULE-BMS]） |
| 光伏接口 | MPPT × 2，单路最大 2500 W，总计 5 kW |
| 电网接口 | 单相 240 V / 60 Hz，最大 100 A |
| 并网逆变器 | 纯正弦波，输出效率 ≥ 94%，THD < 3% |

## 业务流程

### RULE-HE-001：电网 / 离网自动切换（ATS）

**电网掉电 → 切换至储能/逆变器供电：**

```
CT 传感器检测电网电压 → 电网电压跌至 < 80 V（单相 120 V 基准 × 2/3）
  → ATS 控制器触发（硬件独立检测，不依赖 MCU 轮询）
  → T+0ms:   ATS 主开关断开电网侧（K_GRID 继电器 OFF）
  → T+5ms:   检测 K_GRID 实际断开（反馈信号确认，超时 10 ms 报错）[CONSTRAINT:timing]
  → T+10ms:  发送指令给 DELTA Pro Ultra BMS 启动逆变器 [详见 RULE-BMS §RULE-BMS-007]
  → T+25ms:  逆变器输出电压稳定（240 V ±5 V，频率 60 Hz ±0.5 Hz）[CONSTRAINT:timing]
  → T+28ms:  ATS 闭合储能侧（K_BATT 继电器 ON）
  → T+30ms:  负载恢复供电（全程 ≤ 30 ms [CONSTRAINT:timing]）
```

**电网恢复 → 切回电网供电：**

```
电网电压恢复 > 100 V 且持续 ≥ 5 s（防止电网抖动时频繁切换）
  → 逆变器执行电压相位同步（与电网频率相差 < 0.1 Hz，相位差 < 5°）
  → 相位对齐完成后：断开 K_BATT → 闭合 K_GRID
  → 电网供电恢复，逆变器转入充电/待机模式
```

[MUST NOT] K_GRID 和 K_BATT 同时处于闭合状态（防止储能逆变器与电网短路，违反 NEC 690.61 防孤岛要求）。  
[MUST] 两个继电器之间的切换间隔 ≥ 5 ms（死区时间）[CONSTRAINT:safety]。  
[CONSTRAINT:timing] ATS 全程切换时间 ≤ 30 ms，符合关键负载（医疗、服务器）UPS 要求。

### RULE-HE-002：负载优先级管理

负载通道分级（出厂默认配置，用户可通过 App 调整）：

| 优先级 | 通道组 | 典型负载 | 断电触发条件 |
|--------|--------|---------|------------|
| P1（关键）| 通道 1–2 | 医疗设备、服务器 | [MUST NOT] 在 SoC > 5% 时切断 |
| P2（重要）| 通道 3–5 | 冰箱、Wi-Fi、安全摄像 | SoC < 20% 时自动切断 |
| P3（一般）| 通道 6–8 | 照明、电视、电风扇 | SoC < 35% 时自动切断 |
| P4（可控）| 通道 9–10 | 电动汽车充电、烘干机 | SoC < 50% 或功率受限时切断 |

```
负载功率超限处理（总负载 > 3600 W）：
  → 计算当前各优先级实际功率（CT 实时采样）
  → 从 P4 开始逐级切断，直到总功率 ≤ 3600 W
  → 切断前发送 App 通知（提前 5 s 预警，紧急情况立即切断）
  → 记录切断事件（时间戳 + 通道号 + 原因码）
```

[MUST] 负载切断/恢复操作通过 RS485 Modbus RTU 命令控制断路器（[详见 §寄存器-Modbus]）。  
[SHOULD] 电网恢复后优先恢复 P4 负载，恢复时序从 P1 到 P4 依次确认，每路间隔 2 s（防止冲击）。

### RULE-HE-003：光伏-储能-电网协调（能量流向仲裁）

能量仲裁优先级（由高到低）：

```
1. 满足当前负载用电需求（最高优先级）
2. 光伏剩余电力 → 优先充储能电池
3. 储能 SoC > 100%（满电）且光伏仍有剩余 → 允许并网馈电（需电网许可且已开通）
4. 光伏不足且储能 SoC > SOC_MIN → 储能补充负载
5. 储能不足 → 电网补充（按峰谷电价策略调度）
```

逆变器工作模式切换：

| 模式 | 触发条件 | 逆变器行为 |
|------|---------|-----------|
| Solar-Priority | 光伏功率 ≥ 负载功率 | 光伏直供 + 余电充储能 |
| Backup-Priority | 电网停电 | 储能逆变输出，MPPT 同步充电 |
| Grid-Charge | 储能 SoC < SOC_CHG 且非峰时段 | 电网充储能（按配置时间段） |
| Feed-in | 储能满电 + 光伏剩余 + 并网许可 | 向电网馈电（限制 ≤ 3600 W） |

[MUST NOT] 在 Backup-Priority 模式下向电网馈电（孤岛运行，防逆送电）[CONSTRAINT:safety]。  
[MUST] 模式切换时记录切换原因和当前 SoC、光伏功率、负载功率到事件日志（[详见 RULE-IOT-CLOUD §RULE-IOT-003]）。

### RULE-HE-004：CT 传感器电流采样

```
CT 传感器安装位置：
  - CT_MAIN: 电网主进线（量程 ±200 A，变比 3000:1）
  - CT_PV1/CT_PV2: 光伏输入（量程 ±50 A，变比 1000:1）
  - CT_LOAD_1~10: 10 路负载回路（量程 ±30 A，变比 500:1）

采样流程：
  → 12-bit ADC（STM32 内建，参考电压 3.3 V）采样各 CT 输出电压
  → 采样率：每路 4000 SPS [CONSTRAINT:timing]（支持 60 Hz × 66 次 = 4000 次/s，捕获完整工频周期）
  → 对每路执行 RMS 计算：I_rms = √(Σi²/N)，N = 66 个采样点（单个工频周期）
  → 功率计算：P = V_grid × I_rms × cos(φ)（功率因数角 φ 由电压相位与电流相位差获得）
  → 结果写入 Modbus 寄存器供 Hub 读取（[详见 §寄存器-CT_DATA]）
```

[MUST] CT 传感器安装必须保证极性正确（电流方向与标注箭头一致），否则功率方向判断错误。  
[CONSTRAINT:timing] 所有 CT 通道采样结果的时间对齐误差 ≤ 250 μs（1 个采样间隔）。  
[SHOULD] 出厂前执行 CT 校准：在已知电流下记录 ADC 读数，写入 REG_CT_CAL_FACTOR [详见 §寄存器-CT_CAL]。

### RULE-HE-005：并网逆变器控制（防孤岛保护）

**并网条件检查（MUST 全部满足）：**

1. 电网电压在正常范围（100–130 V，单相 120 V 基准）
2. 电网频率在正常范围（59.3–60.5 Hz）
3. 储能 SoC > 5%（保留最低备电量）
4. 孤岛检测通过（频率偏移检测 + 主动移频检测，见下）

**孤岛检测（主动频移法）：**

```
每 100 ms 向逆变器输出注入微小频率偏移（±0.05 Hz）[CONSTRAINT:timing]
  → 若电网正常：电网频率锁定，注入偏移被吸收，频率保持稳定
  → 若电网已断开（孤岛）：频率偏移累积，检测到频率漂移 > 0.5 Hz / s
  → 孤岛判断成立 → 逆变器 ≤ 100 ms 内停止输出 [CONSTRAINT:safety]
```

[MUST NOT] 在孤岛检测结果不明确时允许并网运行（宁可误判停机，不可漏判持续并网）。  
[CONSTRAINT:safety] 孤岛检测到停止输出的响应时间 ≤ 100 ms（符合 IEEE 1547-2018 要求）。

**反送电保护：**

- [MUST NOT] 在 Backup 模式（电网断电）下允许电流流向电网侧
- CT_MAIN 检测到向电网方向电流 > 0.5 A 时立即断开 K_GRID [详见 §时序-ATS]

### RULE-HE-006：电池 SOC 保护区间

SoC 区间定义（用户可在 App 内配置，以下为默认值）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| SOC_MIN_BACKUP | 20% | 备电保留下限，电网存在时不放电至此以下 |
| SOC_MIN_OFFGRID | 5% | 离网时最低放电限制（[MUST NOT] 触发 UVP 保护）|
| SOC_CHG_THRESHOLD | 80% | 低于此值时允许电网充电 |
| SOC_FEED_IN | 100% | 满足此值才允许向电网馈电 |
| SOC_PV_PRIORITY | 30% | 低于此值时 MPPT 优先充储能（不向电网馈电） |

```
峰谷电价策略（可选功能，用户需配置电价时间表）：
  谷时段（凌晨 00:00–07:00）：若 SoC < SOC_CHG_THRESHOLD → 启动电网充电
  峰时段（08:00–22:00）：    优先使用储能，减少从电网取电
  策略执行间隔：每 1 min 评估一次 [CONSTRAINT:timing]
```

[MUST] 备电模式（App 设置）下 SOC_MIN_BACKUP 不允许低于 10%（防止停电后无电可用）。

### RULE-HE-007：RS485 / CAN 总线通信

**RS485 Modbus RTU（SHP2 ↔ 各负载断路器模组）：**

```
波特率：9600 bps（固定，不可配置）
从机地址：0x01–0x0A（对应 10 路断路器）
Hub 主机地址：0x00（广播）

心跳超时：Hub 每 5 s 轮询所有从机 [CONSTRAINT:timing]
  → 某从机连续 3 次无响应（15 s）→ 触发 RS485_TIMEOUT 告警
  → 超时从机通道标记为 UNKNOWN，对应负载状态显示离线

帧超时重发：
  → 单帧响应超时：50 ms
  → 重发 3 次后放弃，记录通信失败事件
```

**CAN 2.0B（SHP2 ↔ DELTA Pro Ultra BMS）：**

- 波特率：500 kbps
- 参见 RULE-BMS §附录 D.2 中的帧格式定义（CAN ID 0x18BMS001/0x18BMS002）
- SHP2 → BMS 指令帧（ID: 0x18SHP001，触发类型，非周期）：

```
字节  | 描述
------+---------------------------------
Byte0 | 指令类型（0x01=启动逆变器 0x02=停止 0x03=充电开始 0x04=充电停止）
Byte1 | 目标 SoC（仅充电指令有效，0–100）
Byte2–7 | Reserved（填 0x00）
```

[MUST] CAN 总线上所有节点 ID 唯一，Hub 在初始化时扫描总线枚举设备（[详见 §寄存器-CAN_NODE_TABLE]）。  
[CONSTRAINT:timing] BMS 状态帧（0x18BMS001）周期 100 ms，超过 500 ms 未收到则 BMS 被判断为离线。

### RULE-HE-008：系统级故障隔离

故障隔离策略（分级处置）：

| 故障类型 | 检测来源 | 隔离动作 | 恢复方式 |
|---------|---------|---------|---------|
| 单路负载过载（CT > 30 A 持续 1 s）| CT_LOAD_n | 断开对应断路器 | 用户手动/App 恢复 |
| 总线通信故障（RS485 超时）| Hub 轮询 | 隔离故障从机，其余正常运行 | 从机自动重连 |
| BMS 离线（CAN 超时 500 ms）| CAN 帧接收 | 停止向 BMS 发送指令，保持当前状态 | BMS 重新上线后同步 |
| ATS 继电器故障（反馈不一致）| REG_ATS_STATUS | 切断所有 K，进入安全模式 | 人工检查后复位 |
| 逆变器过温（> 80°C）| 逆变器内部 NTC | 降额 50%，> 90°C 停机 | 温度 < 70°C 自动恢复 |
| 孤岛误检（频率波动）| 孤岛检测算法 | 停止并网，5 s 后重新检测 | 条件满足后自动恢复 |

**故障码汇总上报：**
- 所有故障事件写入 REG_EVENT_LOG（环形缓冲区，容量 64 条）[详见 §寄存器-EVENT_LOG]
- 通过 IoT 云端通道上报（[详见 RULE-IOT-CLOUD §RULE-IOT-003]），QoS 1

## 异常处理

| 场景 | 检测方式 | 动作 | 恢复条件 | 告警级别 | 对应 AC |
|------|---------|------|---------|---------|---------|
| 电网掉电（V < 80 V）| CT_MAIN + 电压采样 | ATS 切换至储能（≤ 30 ms）[详见 §时序-ATS] | 电网恢复 > 100 V 持续 5 s | 1-严重 | AC-1 |
| 负载总功率超限（> 3600 W）| CT 实时汇总 | 按优先级逐级切断 P4→P3→P2 | 功率 < 3200 W（20% 回差）| 2-一般 | AC-4 |
| 孤岛检测触发 | 主动频移检测 | 逆变器停机（≤ 100 ms）| 5 s 后重新检测通过 | 1-严重 | AC-7 |
| ATS 继电器反馈不一致 | REG_ATS_STATUS 位校验 | 切断所有继电器，进入 FAULT 安全模式 | 人工复位 + 运维检查 | 0-紧急 | AC-2 |
| BMS 通信超时（> 500 ms）| CAN 帧计时 | 保持当前逆变器状态，停止发送指令 | BMS 重新上线后同步 | 1-严重 | AC-9 |
| RS485 从机离线（> 15 s）| Hub 轮询计时 | 标记从机 UNKNOWN，隔离该通道 | 从机恢复响应 | 2-一般 | AC-10 |
| CT 传感器故障（读数异常）| ADC 量程检查 | 使用该 CT 的功率显示为 "–"，不影响其他通道 | CT 更换后重新校准 | 2-一般 | AC-6 |
| 并网反送电检测（Backup 模式）| CT_MAIN 方向检测 | 立即断开 K_GRID | K_GRID 确认断开后告警清除 | 0-紧急 | AC-8 |

## 验收标准

**RULE-HE-001（ATS 切换）：**

AC-1: 电网电压跌至 < 80 V → ATS 切换完成且负载恢复供电，全程 ≤ 30 ms，可用示波器在 K_BATT 端测量  
AC-2: K_GRID 断开反馈超时（> 10 ms 未收到确认）→ 进入 FAULT 模式，停止 ATS 切换序列

**RULE-HE-002（负载管理）：**

AC-3: P1 通道（1–2）在 SoC > 5% 时 [MUST NOT] 因负载超限被切断，仅在 SoC ≤ 5% 时允许  
AC-4: 总功率 > 3600 W → 先切断 P4，若仍超限则切断 P3，依次类推；不超限则不切断任何通道

**RULE-HE-004（CT 采样）：**

AC-5: CT_MAIN 采样误差 ≤ 1%（与标准电能表对比验证，100 A 时误差 ≤ 1 A）  
AC-6: 单路 CT 故障（ADC 读数超量程）→ 该路显示 "–"，其余 9 路正常工作，系统不进入 FAULT

**RULE-HE-005（并网 / 孤岛）：**

AC-7: 孤岛条件成立（频率偏移 > 0.5 Hz/s）→ 逆变器在 100 ms 内停止输出  
AC-8: Backup 模式下 CT_MAIN 检测到向电网方向电流 > 0.5 A → 立即断开 K_GRID（≤ 50 ms）

**RULE-HE-007（总线通信）：**

AC-9: BMS CAN 帧超时 500 ms → 记录 BMS_OFFLINE 事件，停止向 BMS 发指令，不影响负载管理  
AC-10: RS485 从机连续 3 次无响应 → 标记 UNKNOWN，不影响其余从机的正常轮询

**RULE-HE-003（能量协调）：**

AC-11: Solar-Priority 模式下光伏功率 ≥ 负载功率 → 不从电网取电（CT_MAIN 电网进线方向电流 ≈ 0）  
AC-12: SoC > SOC_FEED_IN（默认 100%）且并网许可 → 馈电功率 ≤ 3600 W，不超过配置上限

## 附录 A：Modbus RTU 寄存器表（SHP2，主机 → 断路器从机）

协议：Modbus RTU，波特率 9600，8N1，从机地址 0x01–0x0A。

| 寄存器地址 | 功能码 | 寄存器名 | R/W | 单位 | 说明 |
|-----------|--------|---------|-----|------|------|
| 0x0001 | 03/06 | REG_BREAKER_CTRL | R/W | — | 断路器控制（0x0000=断开 0x0001=闭合）|
| 0x0002 | 03 | REG_BREAKER_STATUS | R | — | 实际状态（0=断开 1=闭合 2=故障）→ AC-3 |
| 0x0003 | 03 | REG_LOAD_POWER_H | R | W | 当前功率高字节（uint32，LSB = 1 W）|
| 0x0004 | 03 | REG_LOAD_POWER_L | R | W | 当前功率低字节 |
| 0x0005 | 03 | REG_LOAD_CURRENT | R | mA | 负载电流（uint16，量程 0–30000 mA）→ AC-5 |

```

```

## 附录 B：CAN 2.0B 帧格式（SHP2 → BMS 指令帧）

CAN 2.0B，29-bit 扩展 ID，波特率 500 kbps。

**帧 ID 编码规则（29-bit）：**

```
[28:24] 优先级（0=最高，7=最低，默认 3）
[23:16] 目标设备类型（0x18=BMS，0x19=SHP2，0x1A=光伏控制器）
[15:8]  源设备类型
[7:0]   帧类型（0x01=状态帧，0x02=指令帧，0x03=确认帧）
```

**SHP2 → BMS 指令帧（ID: 0x1918BMS02，触发型，无周期）：**

| 字节 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | CMD_TYPE | uint8 | 0x01=启逆变 0x02=停逆变 0x03=开始充电 0x04=停止充电 0x05=设定限功率 |
| 1 | PARAM_H | uint8 | 参数高字节（0x05 时 = 功率限制 W 的高字节）|
| 2 | PARAM_L | uint8 | 参数低字节 |
| 3 | SEQ_NUM | uint8 | 序列号（0–255 循环，BMS 回 ACK 时携带相同值）|
| 4–7 | Reserved | — | 填 0x00 |

**BMS ACK 帧（ID: 0x1819SHP03，回应 SHP2 指令）：**

| 字节 | 字段 | 说明 |
|------|------|------|
| 0 | ACK_SEQ | 与指令帧 SEQ_NUM 相同 |
| 1 | RESULT | 0x00=成功 0x01=拒绝（故障中）0x02=超时 |
| 2–7 | Reserved | — |

[CONSTRAINT:timing] SHP2 发出指令后等待 BMS ACK，超时时间 200 ms，超时后重发 2 次，仍无响应则记录 CAN_CMD_TIMEOUT 事件。
