# 讲师手册 - 第三部分：全链路应用 —— AI-Native SDLC 实战

## 课程目标
将 Agent 注入研发全生命周期的每个环节，展示如何通过人机协同实现端到端的研发效能飞跃。

---

## 3.1 需求发现与产品定义（Discovery & Spec）

### **要点 1：自动化竞品分析与行业扫描**
- **核心结论**：AI 可以显著加速“需求发散”阶段的信息获取。
- **讲解内容**：
    - 利用 Deep Research Agent 进行特定领域的功能对比（Benchmark）。
    - 快速生成包含行业痛点分析、核心竞品清单和功能矩阵的初步报告。
- **举例细节**：
    - **演示建议**：演示使用 Perplexity API 自动生成一份“主流支付 SDK 功能对比”的竞品分析文档。

### **要点 2：从模糊到精确的 Spec 转化**
- **核心结论**：Spec 是 SDLC 的新起点，Claude Artifacts 提供了极佳的实时协作 Spec 环境。
- **讲解内容**：
    - 利用大模型的“反向询问”能力，通过对话不断细化需求，直至生成无歧义的 PRD。
    - 规格说明应包含：领域模型、数据流、UI 组件语义、API 定义。
- **举例细节**：
    - **协作演示**：在 Claude 界面中输入模糊需求，引导模型生成包含 mermaid 图表和接口列表的 Artifact。

### **要点 3：User Story 自动拆解**
- **核心结论**：利用模型的能力，根据复杂度、业务价值和依赖关系自动拆解任务（Sub-tasks）。
- **讲解内容**：
    - 结合卡农模型（Kano Model）识别哪些是必备功能（Must-have），哪些是魅力属性（Delighter）。
- **举例细节**：
    - **模板展示**：一个 User Story 拆解结果，包括标题、验收标准（Acceptance Criteria）和预估 Story Points。

## 3.2 UI 原型设计与“代码即视觉”

### **要点 1：快速原型工具链（v0.dev / Lovable）**
- **核心结论**：UI 交付正从“设计稿”向“可运行组件”跃迁。
- **讲解内容**：
    - 介绍 v0、Lovable、Bolt 等工具：通过文本或手绘草图直接生成 React/Vue + Tailwind 代码。
    - “视觉驱动开发”：不再需要漫长的 Figma 转代码过程，原型即最终组件的基础。
- **举例细节**：
    - **对比场景**：Figma 传统链路（3天）vs. v0.dev 生成并调整（30分钟）。

### **要点 2：Design-to-Code 闭环**
- **核心结论**：基于语义化组件（Shadcn/UI 等）和 CSS 框架（Tailwind），实现设计与代码的自动映射。
- **讲解内容**：
    - 如何建立一套 Agent 可理解的设计系统（Design System）。
- **举例细节**：
    - **演示建议**：展示如何通过 Figma 插件或 AI 工具一键生成符合团队规范的代码段。

## 3.3 开发阶段：Repo 即 Agent 的“操作系统”

### **要点 1：Agent 协同开发模式**
- **核心结论**：多 Agent 协作系统（如前端 Agent 与后端 Agent）通过标准契约（Contract）解耦。
- **讲解内容**：
    - 通过 API 定义（如 Swagger/OpenAPI）先行，两端 Agent 同时基于该契约进行开发和测试。
- **举例细节**：
    - **流程示意**：后端 Agent 生成 Golang 代码 -> 前端 Agent 生成对应的 TypeScript 类型定义 -> 接口联通测试。

### **要点 2：构建“知识地图索引”**
- **核心结论**：降低 Agent 推理时的“上下文搜索”成本。
- **讲解内容**：
    - 定期生成代码库的结构索引、依赖树和公共组件库目录，帮助 Agent 秒级锁定修改位置。
- **举例细节**：
    - **工具应用**：展示如何使用 `tree` 结构的 README 或索引文件辅助 Agent 理解大型 Repo。

## 3.4 测试与质量：从自动生成到自愈保障

### **要点 1：测试用例自动推导与 Synthetic Data**
- **核心结论**：AI 擅长覆盖各种奇特的边界条件（Edge Cases）。
- **讲解内容**：
    - 基于逻辑流自动生成 Happy Path 和 Error Handling 脚本。
    - 利用 LLM 生成各种仿真 Mock 数据（姓名、电话、JSON 异常格式）。
- **举例细节**：
    - **对比演示**：手动编写 5 个用例 vs. AI 推导生成的 50 个覆盖全路径的用例。

### **要点 2：可观测性驱动的自愈**
- **核心结论**：将 Sentry/Log 与修复 Agent 挂钩，实现 Bug 的自动闭环。
- **讲解内容**：
    - Agent 读取报错堆栈 -> 在本地重现 Bug -> 编写修复代码 -> 运行测试验证 -> 提交修复。
- **举例细节**：
    - **实战演示**：演示一个线上报错触发 Webhook，Agent 在 2 分钟内提交一个经过验证的 Bugfix PR。

## 3.5 自动化运维与智能 Ops

### **要点 1：根因分析（RCA）Agent**
- **核心结论**：AI 在海量指标和日志中寻找相关性的效率远超人工。
- **讲解内容**：
    - 多维数据聚合：指标、分布式链路追踪（Trace）与日志（Log）的综合研判。
- **举例细节**：
    - **分析演示**：给定一段复杂的 K8s 报错和 Prometheus 指标图表，看 AI 如何准确定位到底层磁盘挂载失败的根因。
