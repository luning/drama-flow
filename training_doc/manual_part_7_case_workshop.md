# 讲师手册 - 第七部分：综合案例工作坊 —— 模拟真实战场

## 课程目标
通过一个完整的闭环实战案例，让学员亲手操作 AI-Native 研发全流程，从无到有构建一个生产级系统。

---

## 7.1 案例背景：构建“跨端个性化推荐系统”

### **要点 1：产品定义与调研**
- **核心结论**：快速收敛模糊概念，转化为确定性的 PRD。
- **讲解内容**：
    - 利用 Perplexity 调研当前主流的推荐算法模型（协同过滤、向量检索、深度学习）。
    - 快速生成一份 PRD，明确：系统架构图、数据输入格式、输出 API 定义。
- **举例细节**：
    - **实战操作**：引导学员输入提示词，让模型在 10 分钟内生成包含 3 个核心端点（Endpoint）的 PRD。

### **要点 2：UI 原型极速产出**
- **核心结论**：原型即最终组件的语义基座。
- **讲解内容**：
    - 使用 v0.dev 快速生成推荐列表的 Dashboard。
    - 强调语义化描述的重要性，为下一步 Agent 实现逻辑打好基础。
- **举例细节**：
    - **实战操作**：学员在 v0.dev 中通过对话调整页面布局和交互逻辑。

### **要点 3：存量代码的 Agent 友好改造**
- **核心结论**：建立知识图谱是 Agent 高效协作的前提。
- **讲解内容**：
    - 补充已有代码库的“模块级 MD”。
    - 使用 IDE 插件（如 Cursor）建立完整的项目索引（Code Indexing）。
- **举例细节**：
    - **实战操作**：为老旧的算法模块编写 README，并使用 `@Codebase` 命令进行全局上下文分析。

### **要点 4：并行开发与沙箱执行**
- **核心结论**：分派不同的 Agent 在隔离环境中独立完成任务。
- **讲解内容**：
    - 分派三个任务：1. 后端推荐 API 实现；2. 算法引擎逻辑；3. 监控面板。
    - 在沙箱中执行 `npm run dev` 或 `pytest` 进行验证。
- **举例细节**：
    - **实战操作**：使用 `Aider` 或 `Claude Code` 终端 Agent 进行并行文件修改。

### **要点 5：Bug 注入与自愈测试**
- **核心结论**：体验“报错即修复”的闭环反馈。
- **讲解内容**：
    - 人工注入一个逻辑 Bug（如：推荐列表返回空数组）。
    - 让 Agent 读取日志/报错信息，分析根因，并自主提交修复 PR。
- **举例细节**：
    - **实战操作**：制造一个后端接口 500 错误，观察 Agent 如何通过报错堆栈定位到某个 Python 依赖包版本冲突并修复。

## 7.2 总结与复盘

### **要点**
- **核心结论**：AI-Native 研发不是取代人，而是让人处理更高维度的问题。
- **讲解内容**：
    - 复盘全流程：哪些环节人介入了？哪些环节 Agent 处理得比人更好？
    - 讨论在实际公司业务中落地的最大挑战和应对策略。
- **举例细节**：
    - **互动研讨**：提问学员“假如明天你回到公司，你会尝试把 AI 注入到哪个最痛点的环节？”
