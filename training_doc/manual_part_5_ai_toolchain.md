# 讲师手册 - 第五部分：工具全景图 —— 打造 AI 研发工具链

## 课程目标
在琳琅满目的 AI 工具生态中，帮助学员进行精准选型，构建适合自己团队的 AI-Native 研发工具栈。

---

## 5.1 需求与 UI/原型类

### **要点 1：调研与文档辅助**
- **核心结论**：AI 已成为获取行业知识和撰写文档的首选助手。
- **讲解内容**：
    - **ChatGPT (Deep Research)**：适用于深度行业背景分析。
    - **Perplexity**：实时信息搜索的最佳选择。
    - **NotebookLM**：处理海量私有 PDF 和知识文档。
- **举例细节**：
    - **场景推荐**：让 Perplexity 搜索最新的 React 19 新特性并整理成项目升级指南。

### **要点 2：设计与交互原型**
- **核心结论**：原型工具正在快速“代码化”。
- **讲解内容**：
    - **v0.dev (Vercel)**：最强 React + Tailwind 原型。
    - **Lovable.dev / Bolt.new**：端到端（前端 + 简单后端）的快速生成。
    - **Uizard / Galileo AI**：视觉稿驱动的界面生成。
- **举例细节**：
    - **实战对比**：展示在 v0.dev 中通过对话描述一个“带暗黑模式的响应式侧边栏”的过程。

---

## 5.2 编码与 Agent 开发类

### **要点 1：交互式 IDE 与原生终端 Agent**
- **核心结论**：从 IDE 插件进化到全能型 Agent IDE 和终端 Agent。
- **讲解内容**：
    - **Cursor / Windsurf / Trae**：集成推理模型的下一代 IDE，具备理解项目全局的能力。
    - **Claude Code / Gemini CLI / Aider**：运行在终端的“超级开发者”，直接在命令行操作文件、运行命令、提交 Git。
- **举例细节**：
    - **IDE 演示**：展示 Cursor 的 `Composer` 模式如何通过一个指令修改涉及 5 个文件的业务逻辑。
    - **终端演示**：使用 `claude-code` 运行“查找所有未写单元测试的函数并补充用例”。

### **要点 2：Agent 开发框架**
- **核心结论**：构建自定义 Agent 需要强大的控制力。
- **讲解内容**：
    - **LangGraph**：复杂的、循环的图架构 Agent 编排。
    - **CrewAI**：多角色（Role-playing）协作的 Agent 团队。
    - **PydanticAI**：强类型的 Agent 框架，适合追求极致确定性的工程师。
- **举例细节**：
    - **架构图示**：一个使用 LangGraph 定义的代码修复流程图，包含：错误捕获节点 -> 修改节点 -> 验证节点 -> 反复循环。

## 5.3 基础设施与评估类

### **要点 1：模型托管与成本优化**
- **核心结论**：灵活切换模型是降低成本、提升性能的关键。
- **讲解内容**：
    - **OpenRouter**：一键集成全球主流 LLM 接口。
    - **DeepSeek API**：目前性价比最高的国产推理模型选择。
    - **Ollama**：在本地/私有环境运行 70B 及以下模型的最佳方案。
- **举例细节**：
    - **性能对比**：DeepSeek-V3 与 GPT-4o 在代码理解任务上的速度与价格差异。

### **要点 2：质量评估（Eval）与监控**
- **核心结论**：Agent 的产出必须是可量化、可测试的。
- **讲解内容**：
    - **PromptFoo**：针对 Prompt 的自动化回归测试。
    - **LangSmith / Weights & Biases**：监控 Agent 的思考链（Trace）和 Token 消耗。
- **举例细节**：
    - **评估演示**：演示 PromptFoo 如何自动化测试 50 种不同的输入，并打分看哪个 Prompt 的 Bugfix 成功率最高。
