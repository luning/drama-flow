### 必带

- [ ] 笔记本电脑 + **电源适配器**（两天实战，电量消耗大）

### 软件环境

> 请在课前完成安装，尽量避免课上花大量时间安装和排查问题。

- [ ] **Java 17** — Android Studio 依赖
- [ ] **Android Studio**（最新稳定版）— 安装时勾选 API 34 SDK；提前创建 Pixel 6 Pro arm64-v8a 模拟器并启动一次确认可运行
- [ ] **VS Code**（最新稳定版）— 用于 H5（Vue3）+ Python（FastAPI）开发；Java 后端背景学员可用 **IntelliJ IDEA** 替代
- [ ] **Claude Code 插件** — 在 VS Code 或 IntelliJ 中安装均可；Android Studio 同理
- [ ] **Python 3.10+** — 在 `backend/` 目录下提前执行 `python -m venv drama-flow` 创建好虚拟环境
- [ ] **Node.js 20 LTS** — 用于 Vue3 / Vite H5 开发
- [ ] **Git** — 课程有预设分支，用于掉队时同步代码

### API Key

课程核心 AI 工具为 **Claude Code**，搭配国产大模型作为辅助后端。以下二选一，公司或个人提前申请并确认可用：

- [ ] **GLM（智谱 AI）** — 申请入口：open.bigmodel.cn，配置到 Claude Code 的自定义模型后端
- [ ] **DeepSeek** — 申请入口：platform.deepseek.com，配置方式同上

二选一即可。
